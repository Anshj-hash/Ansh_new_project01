STUDENT PLACEMENT MANAGEMENT SYSTEM
===================================

Project type: Front-end website (HTML, CSS and JavaScript)
Project name: PlacePro - Student Placement Management System

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or right-click and open it in Chrome/Edge/Firefox.
4. No installation or server is required.

FEATURES
- Dashboard with placement statistics
- Add, view, search and delete student records
- Student CGPA and backlog eligibility indicator
- Add and manage recruiting companies
- Create and view campus job drives
- Add student applications
- Update application status: Applied, Shortlisted, Selected or Rejected
- Search and filter records
- Responsive layout for mobile and desktop
- Data is saved in browser localStorage

IMPORTANT PROJECT NOTE
This is a front-end academic demonstration project. Data is stored in the browser
where the website is opened. It does not include a shared online database,
authentication, server-side security, or real company integrations.

SUGGESTED FUTURE ENHANCEMENTS
- Admin/student login with role-based access
- PHP/Node.js backend and MySQL database
- Resume upload and interview scheduling
- Email and SMS notifications
- Reports and placement analytics

TECHNOLOGIES
HTML5, CSS3, JavaScript (ES6), Browser Local Storage
